# Pratyush-s-Personal-Portfolio-Project
Pratyush's Personal Portfolio

Hey! Welcome to my little corner of the internet! <a href="https://pratyush-m-code.github.io/">Here</a>

This is my personal portfolio website, built from scratch with HTML, CSS, and JavaScript.

What's this website about?

Basically, it's a place where I can show off:

* A little bit about myself
* Projects and things I'm currently learning
* My interests in Physics, AI, coding, and German
* Some of my older Scratch projects
* Ways to get in touch with me

There's also a sleeping red panda because... well, why wouldn't there be a sleeping red panda?
🛠️ Built With

* HTML – Structure of the website
* CSS – Styling, layout, colours, and the jungle theme
* JavaScript – The pixelated corner effect
* Font Awesome – Social/contact icons
* Google Fonts – Pixelify Sans
* Just the basics. UwU

The Theme

The website is loosely inspired by a pixel-art jungle.

The different sections represent:

1. Canopy – Navigation
2. Forest – Main content
3. Projects – Things I'm working on / interested in
4. Roots – Contact links and footer

I also made a little JavaScript function that creates the pixelated corners using CSS clip-path, because normal rounded corners were too boring.
